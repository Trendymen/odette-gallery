> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. 用户已要求直接执行，不重复询问；不创建 worktree，不提交或推送。

**Goal:** 把在用画廊及图像迁到独立工程，集中归档未用素材和来源记录。

- 当前 544 作品、576 版本、2258 图片；manifest、policy 和两份停服后最终状态保持原文，不重新筛选或重裁，不应用删除标记。
- 127.0.0.1:58855 和 odette_mousepad_updated 不变；同一时刻一个正式写入服务。自动化测试只使用临时状态和临时端口。
- archive、state、node_modules 和过程材料 Git 忽略；不用框架、数据库、Git LFS，不 add/commit/push。

## Review Focus

- 启动 cwd 与项目不一致：从 /tmp 启动实际入口，解析新根正确。
- 图片缺失或 SHA 不符：验证失败退出，拒绝清理旧副本。
- 归档目标冲突或源软链接越界：迁移报错，不覆盖已有文件或跟随未知链接。
- 生成时 policy 错误或 ID 非法：失败关闭，不产生可供浏览的排除作品。
- 切换期间用户继续勾选：停服后再捕获最终状态，双文件逐字节读回。
